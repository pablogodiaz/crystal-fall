# crystal-fall

Isometric zombie roguelike built with Three.js. Find each city's Crystal, shatter it, survive the horde, and take the road to the next city. Scavenge cars, dumpsters, crates and buildings for ammo, food and medicine, and craft molotovs and pipe bombs from scrap.

Runs straight from GitHub Pages: plain ES modules, no build step. To play locally:

```bash
python3 -m http.server 8000
```

then open http://localhost:8000. See [CLAUDE.md](CLAUDE.md) for design notes and code layout.
